# Estilo del código

- Cuatro espacios de indentación y separación entre métodos.
- Una sentencia por línea en C#; bloques y argumentos legibles.
- Clases, contratos y componentes en archivos propios.
- Evitar comentarios que repiten el código; conservar licencias.
- No editar migraciones, snapshots ni archivos generados para ajustar estilo.
- Compilar y ejecutar pruebas en Debug.

La configuración de edición está en `.editorconfig`. Kotlin sigue el formato Kotlinlang de ktfmt; los scripts Python usan Black.
